# LokAI 2.0

An AI legal-information companion for Indian citizens — a **portfolio prototype**: fully visual,
deterministic, offline. No live AI, no network, no file uploads, no microphone. Not a lawyer, and it says so.

Built per the LokAI 2.0 phased build prompt (Phases 0–2 complete) on a visual foundation re-implemented from
the Interfere design system's token architecture (design.interfere.com — docs-only; all code here is ours).

## Commands

```bash
npm run dev       # local dev — ALWAYS this
npm run verify    # integrity + design-law + WCAG AA gate (light & dark)
npm run typecheck # tsc --noEmit (strict)
npm run build     # typecheck + vite build
npm run gates     # verify + typecheck + build, in one
```

`npm run preview` serves from `dist/` — build `base` is `./` with hash routing, so the app is embeddable
anywhere (portfolio iframe included).

## Routes (hash)

| Route | What |
|---|---|
| `#/` | The app — empty state → chat spine |
| `#/?s=<scenario>` | Seeded scenario (see below) |
| `#/specimen` | Type specimen — every script × every register; tune the per-script scales here |
| `#/gallery` | Component gallery — every component × every state |
| `#/dev` | Scenario launcher — all flows and states, one link each |

**Scenarios:** `refund-golden` · `refund-caution` · `stop-eviction` · `stop-threat` · `stop-b2b` ·
`error-state` · `offline-state`

## Non-negotiable rules

- **One legal store:** every legal claim lives in `src/app/data/legal-content.ts` with `verified: false` and
  visible `[VERIFY]` markers until the owner verifies. Never invent section numbers, limitation periods, fees
  or helpline numbers.
- **No fabricated confidence:** three plain-language levels only (Clear / Likely—please confirm / Not sure).
  Never a percentage.
- **Downgrade law** (`data/scope-rules.ts`): uncertain classification lands on Caution, never a silent
  Proceed. Hard stops route to the protective stop screen with DLSA help.
- **Typography (A4b):** per-script stacks via `:lang()`; no letter-spacing/uppercase/italic/faux-bold on
  non-Latin; truncation via `Intl.Segmenter`; logical CSS properties; Urdu is RTL.
- **Raw colors/fonts live only in `src/styles/`** — the verify gate enforces this plus WCAG AA on declared
  token pairs in both themes.
- **Fonts are self-hosted** (Fontsource, OFL): Inter Variable, JetBrains Mono, Source Serif 4 + Noto
  Devanagari/Tamil/Nastaliq-Urdu/Naskh-Arabic companions. (Berkeley Mono / Heldane Text from the reference
  system are commercial; these are the licensed stand-ins.)
- Non-English strings are AI-drafted placeholders (`reviewedByNativeSpeaker: false`) until human review.

- `docs/VISUAL-COMPARISON.md` — positioning against ChatGPT and Gemini, with screenshot evidence

# PRODUCT.md — LokAI

*Read by humans and agents before any design or build work. Stable product truth; design decisions live in
DESIGN.md.*

## What this is

LokAI is a mobile-first AI legal-**information** companion for Indian citizens facing consumer disputes and
confusing official notices. It is an evidence organizer and explainer, **not a lawyer**, and it never claims
to give legal advice. Portfolio prototype: deterministic, offline, mock data — no live AI, no network, no
microphone, no file uploads.

## The user

A stressed, non-expert citizen who has just received a legal notice or a consumer injustice. They do not know
their rights, what the proportionate next step is, or whether a step could hurt their position. Voice is their
most natural input; typed text is the universal fallback. They may be in any of five prototype languages:
English, Hindi, Marathi, Tamil, Urdu (RTL).

## The promise

Reduce fear without overpromising. Every answer is checkable, every action is user-approved, and the
assistant's limits are always visible.

## Experience laws (unchanged, from the LokAI 2.0 build prompt)

1. One conversational spine — intake, clarification, documents, next steps in one thread.
2. Ask at most ONE clarifying question before the first useful answer.
3. Reassure about the process, never the outcome.
4. Proportional action ladder — lowest-cost, lowest-risk step first.
5. Every claim is checkable — source links, verification badges, [VERIFY] markers.
6. Honest uncertainty — three plain-language confidence levels, never percentages.
7. User stays in control — nothing leaves the app without explicit review; everything is editable.
8. Scope guardrails — hard stops route to human help (DLSA); uncertain classification downgrades to caution,
   never silently proceeds.

## Boundaries

- Consumer-protection scope only. Eviction/tenancy, criminal/safety, B2B, threats → protective stop.
- No invented statutes, limitation periods, fees, or helpline numbers. All legal content ships
  `verified: false` with [VERIFY] until the owner verifies.
- The notice interpreter explains what a notice SAYS; it never recommends whether to dispute.
- Simulated capabilities (voice, scanning) are always tagged "Simulated in prototype".

## Surfaces

Home (voice-first) · Listening · Review & send · Chat thread · AI response cards · Demand notice (paper) ·
Stop screen · History · Saved · Profile/privacy. 390px framed prototype shell, graceful on desktop.

# DESIGN.md — the LokAI design language

*The design system of record, extracted from the owner-approved mockup (2026-10-26) and the Interfere-derived
semantic architecture. Any agent or human designing a new surface MUST build from this file. Product truth
lives in PRODUCT.md.*

## Temperament

Calm, botanical, official. A patient government-office competence rendered with the softness of a consumer
app — ivory paper, deep botanical green ink, serif moments for the human register. It should feel like a
trusted public institution that finally learned good manners. NOT: techy dark-mode fintech, wellness-spa
pastels, or folkloric "Indian costume" decoration.

## The one signature

The **voice orb**: layered sage gradients that breathe when idle and morph to a faster pulse when listening.
Boldness is spent here and nowhere else. Every other surface is flat, bordered, and quiet. If a design needs
a second gradient anywhere, it is wrong.

## Tokens (implemented in `src/styles/tokens.css` — the ONLY home of raw values)

Semantic architecture (Interfere-derived): `page / shell / container / card / sunken / modal / standout` →
foreground tiers `primary / secondary / tertiary / disabled` → families `brand / positive / warning / danger`
each with `solid(+hover/active) · subtle · fg · on-*` → borders `default / subtle / strong / inverted` →
`focus`, veils, disabled.

- **Light ("ivory garden"):** warm ivory shell, cream cards, green-black ink, forest-green accent.
- **Dark ("night garden"):** deep green-black surfaces, sage text, mint-green accent. Equal citizen, not an
  afterthought; every token pair WCAG-AA checked by `scripts/verify.mjs` in BOTH themes.
- `--c-spark` exists for the logo mark only — never a UI accent.
- `--c-paper` + the `.paper` class are reserved for generated documents (demand notice, receipts).

## Type — three registers, one job each

| Register | Face | Use |
|---|---|---|
| Display / serif | Source Serif 4 | Human moments: greeting headline, listening/review titles, finding-card headings, document body. The "voice of the guide". |
| UI / sans | Inter Variable | Everything interactive and informational: body, labels, chips, tabs, composer. |
| Evidence / mono | JetBrains Mono | Citations, amounts, dates, order numbers, docket stamps. Only inside `lang="en"` content. |

Per-script companions (Noto Devanagari / Tamil / Nastaliq Urdu / Naskh) load via `:lang()`; sizes scale per
script via `[data-script]`. NEVER letter-spacing, uppercase, italic, or faux bold on non-Latin; Latin-only
niceties must be conditioned on `lang === 'en'`. Truncation via `Intl.Segmenter` only. Urdu is RTL; use
logical CSS properties everywhere.

## Layout

- 390px framed prototype shell (centered, hairline frame on desktop), full-bleed on small screens.
- Bottom tab bar: Home · History · Saved · Profile. Top bar: brand + language + theme. The tab bar is the
  only global navigation; in-thread flows use back buttons, never tabs.
- Tone steps separate surfaces; hairline borders articulate cards; shadows only on true floaters (menus,
  modals, the attachment tray).
- Cards: radius 16–20, padding 16, generous internal line-height. Key-point rows and action tiles follow the
  mockup patterns (numbered circles + chevron rows; 3-up icon tiles).

## Motion

Quiet and functional: 150–250ms ease-out for state changes, height-animated disclosures, one orchestrated
orb morph (idle ↔ listening ↔ thinking). Consequence-scaled beat pacing from `lib/engine.ts` (stops resolve
fastest). `prefers-reduced-motion` collapses all of it. No decoration motion anywhere else.

## Components of record

Primitives in `components/ui/` (Button, Chip, Badge, Card, Banner, Disclosure, Field, Checkbox, Skeleton,
icons); domain: chat (Composer, MessageBubble, Thread, QuickReplies, TypingIndicator), trust
(ConfidenceIndicator, VerificationBadge, ReasoningPill), cards (FindingCard, ActionLadder, CautionCard,
CardActions, DemandNoticeReview), stop (StopScreen), voice (VoiceOrb, ListeningScreen, ReviewAndSend).

## Bans

- No second accent, no gradient outside the orb, no glass/blur panels, no decorative blobs.
- No icon libraries — the bespoke set in `ui/icons.tsx` only.
- No status strings outside `data/` vocabularies; no legal text outside `legal-content.ts`.
- No uppercase/tracking on localized labels; no `slice()` truncation; no raw hex in TSX.
- No fabricated confidence (percentages, grounding scores).
- ChatGPT-parity where it helps (docked composer, calm defaults); divergence where the product demands
  (trust chrome, stop screen, paper documents, serif register).

# AGENTS.md — LokAI 2.0 prototype

Portfolio prototype of an Indian legal-AI companion. Deterministic, offline, mock data only — **no live AI,
no network, no OCR, no microphone, no file inputs** (the verify gate greps for all of these; do not defeat it).

## Commands

```bash
npm run dev          # local dev — ALWAYS this
npm run gates        # verify + typecheck + build — run before every commit
npm run verify       # the gate alone
```

No test suite or linter exists; `verify + typecheck + build` are the three gates.

## The four laws

1. **Legal content lives in ONE place.** `src/app/data/legal-content.ts`, schema
   `{ claim, source, sectionRef, verified, lastChecked }`. Everything ships `verified: false` with visible
   `[VERIFY]` markers. No statute numbers, limitation periods, fees or helpline numbers anywhere else — and
   none invented. `verified: true` is an owner-only flip.
2. **No fabricated confidence.** `ConfidenceIndicator` levels: clear / likely / unsure, plain words, never a
   percentage. The reasoning pill must always render the "Simulated in prototype" tag (the gate checks this).
3. **The downgrade law.** `data/scope-rules.ts` classifies input into `proceed | caution | hard-stop`.
   Uncertain → caution, never silent proceed. Hard-stop → the protective `StopScreen` with the DLSA panel
   (placeholder contacts `[VERIFY]`) and the "tell me more" re-entry. Both stop treatments (inverted/light)
   stay behind the toggle — do not delete one.
4. **User stays in control.** Every generative card carries edit / regenerate / discard. The demand notice
   renders on paper stationery behind an explicit consent checkbox; the app itself never sends or exports
   anything (copy-to-clipboard is the only output path).

## Design system — import downward only

```
src/styles/tokens.css   ← the ONLY place raw colors/radii/shadows/font stacks may exist
src/app/components/ui/  ← primitives (Button, Chip, Badge, Card, Banner, Disclosure, Field…)
src/app/components/{chat,trust,cards,stop}/  ← domain components
src/app/pages/          ← routes; never reach past primitives
```

- Use token utilities (`bg-shell`, `text-fg-secondary`, `border-line-default`, `rounded-2xl`…). Raw hex,
  inline `fontFamily`/`fontSize`/`lineHeight` in TSX fail the gate.
- **ONE accent** (deep navy `brand-*`). Saffron exists only inside the logo mark (`--c-spark`), never as UI
  accent. Status colors are semantic only.
- Elevation is border-first (`border-line-default`); shadows (`shadow-default/large/xl`) are rare and soft.
- Light and dark are equal citizens: dark theme = pure re-pointing in `[data-theme="dark"]`. New token pairs
  must be added to the WCAG list in `scripts/verify.mjs` and pass AA in both themes.
- Icons: the bespoke set in `components/ui/icons.tsx` only. No icon libraries.

## Typography (A4b) — the main design problem

- Languages are configured in `data/languages.ts` (en, hi, mr, ta, **ur — RTL**). Adding a language = one
  entry there + `:lang()` stack in tokens.css + strings in `data/i18n.ts`.
- Per-script scale via `[data-script]` root font-size; tune against `#/specimen`, not by eye in screens.
- NEVER letter-spacing, uppercase, italic, or faux bold on non-Latin text. Latin-only niceties must be
  conditioned on `lang === 'en'` (see FindingCard's `labelClass` for the pattern).
- Truncate with `truncateGraphemes` (`lib/format.ts`), never `slice`. Numbers via `formatINR` (en-IN).
- Every screen must hold with long Tamil/Urdu strings: chips wrap, no fixed heights on text.

## Interaction model

- One conversational spine (`pages/ChatPage.tsx`): reassurance + one-sentence restatement → ONE question
  with chips → branch (finding + ladder / caution). Beats are paced by `lib/engine.ts`
  (consequence-scaled, skippable, `prefers-reduced-motion` aware) — no real streaming, no model.
- Scenario seeding via `#/?s=<id>` always resets the conversation (launcher discipline; StrictMode-safe —
  the guard is set only when the timer fires).
- Editing an earlier answer marks downstream cards stale and re-opens the question; never silently rewrites.

## Data conventions

- Fictional sellers only (HomeKart). No real people, letterheads, or case numbers.
- Indian channel metaphors are product copy: **1915**, **e-Daakhil**, **registered post with
  acknowledgement due**, DLSA — always `[VERIFY]`-badged here.
- Urdu/hi/mr/ta strings are AI-drafted (`reviewedByNativeSpeaker: false`) — never present unreviewed content
  as verified, and don't "fix" translations without flagging them.

## Repo neighbors

v1 lives at `D:\portfolio porjects\Lokaifm-main` — read-only reference for content depth (notice
interpreter, localized turn packs, matter intelligence). Port from it phase by phase; don't edit it.
The phased build prompt (`LokAI_2.0_phased_build_prompt.md`, owner's machine) is the product authority.

# LokAI v1 → v2 — Comparison Report

**Date:** 2026-10-25 · **v2 repo:** `D:\portfolio porjects\lokai new` (fresh build, Phases 0–2 complete) · **v1 repo:** `D:\portfolio porjects\Lokaifm-main` (untouched)

Both are deterministic, offline, mock-data prototypes of the same product idea: an AI legal-information
companion for Indian consumers. v2 is not a reskin of v1 — it is a from-scratch rebuild on a new foundation
(the Interfere-derived token architecture + the LokAI 2.0 phased build prompt), carrying over v1's hardest-won
content and design laws rather than its code.

---

## 1. Positioning

| | v1 ("Lokaifm") | v2 ("lokai new") |
|---|---|---|
| **Product shape** | Guided demo journey with a scripted response engine; "portfolio exhibit" first | An actual app in the ChatGPT/Gemini register — one conversational spine, free-typed input, chips, streaming beats |
| **Design foundation** | Bespoke "Vellum" material system (mesh+grain, Instrument Serif law register, warm paper) | Interfere-style semantic token architecture: neutral surfaces, hairline borders, border-first elevation, ONE navy accent |
| **Languages** | en, hi, mr, ta (all LTR) | en, hi, mr, ta **+ Urdu (RTL stress test)**, direction-aware from day one |
| **Routing** | Hash router, desktop/mobile shells, specimen gallery, embed mode | Hash router (embed-safe), 390px framed prototype shell, `#/specimen`, `#/gallery`, `#/dev` launcher |
| **Stack** | React 18, Tailwind 4, motion, sonner, cmdk, icon libraries (2 tiers) | React 19, Tailwind 4, motion, sonner, **zero icon libraries** (one bespoke SVG set), no router dep |

## 2. What v2 does better

**Typography is now a system, not a per-screen effort.** v1 handled Devanagari/Tamil with per-language font
custom properties (`--font-deva`, `--font-tamil`) and hand-checked screens. v2 drives everything from
`:lang()` selectors plus a `[data-script]` root scale (16px Latin, 17.5px Devanagari, 17.25px Tamil, 17px
Urdu) — components pick up script-appropriate stacks and sizes automatically, and the type specimen route
(`#/specimen`) exists precisely to tune those hypotheses. The hard rules (no letter-spacing/uppercase/italic
on non-Latin, `Intl.Segmenter` truncation, logical CSS properties everywhere) are enforced in code review and
partially by the verify gate, not just documented.

**The token architecture is industrial.** v1 had ~25 semantic role variables over a bespoke palette — good,
but single-theme naming (dark mode was a mobile-only re-pointing added late). v2 ships the full Interfere-style
matrix from day one: 7 surfaces, 4 foreground tiers, brand/positive/warning/danger families each with
solid/subtle/foreground/on-* shapes, a complete border set, disabled/inverted/veil tokens — with light AND dark
themes as equal citizens, all WCAG-AA-verified by the gate (34 declared pairs, both themes).

**Trust chrome is calmer and stricter.** v1's groundedClaims/totalClaims counters and 10 gate labels (G0–G9)
were honest but visually heavy. v2 keeps the honesty with less machinery: three-level plain-language confidence
(Clear / Likely—please confirm / Not sure), two-state verification badge, and a reasoning pill that is always
tagged "Simulated in prototype." The [VERIFY] policy is now absolute: every legal entry is `verified:false`
with visible `[VERIFY]` markers, and the gate fails the build if any entry ships verified.

**Interaction model matches user expectations now.** v1's demo engine narrated staged progress through fixed
turn objects; input matching was regex-on-triggers (acknowledged as brittle in v1's own comments). v2 keeps the
good part (consequence-scaled, skippable, reduced-motion-aware beats — stops animate fastest, explains slowest)
but drives it from a real classifier (`scope-rules.ts`) with the **downgrade law** encoded: uncertain input can
never silently proceed; it lands on Caution. Hard-stop classification routes to a protective screen whose TWO
treatments (inverted navy vs light protective card) both exist behind a persisted toggle — v1 never tested the
assumption that the inverted screen feels safer.

**The action ladder is a first-class object.** v1 had next-steps as prepared turn content. v2 ships it as three
expandable disclosures ordered by risk (editable+copyable WhatsApp draft with regenerate → 1915 helpline card
with prep list → demand notice on paper stationery behind an explicit consent checkbox). Nothing is exported or
sent by the app itself; copy-to-clipboard is the only "output."

**States exist as scenarios, not hopes.** `#/dev` launches: golden path, caution branch, three hard stops,
simulated error with retry, offline with disabled composer. All were exercised in a real browser during this
build (see §4).

## 3. What v1 still has that v2 defers (honest regressions)

- **The Marathi BMC notice interpreter** — v1's founding feature: segmented original clauses, per-language
  interpretations, field-level mono citation stamps, tap-to-source correspondence. This is Phase 3 of the v2
  plan; the data (v1 `noticeInterpretation.ts`) ports cleanly when that phase starts.
- **Depth of localized content.** v1 localized ~500 strings across turn chrome, stop families, glossary and
  flashcards in 4 languages. v2 localizes the UI chrome + conversational beats in 5 languages, but card bodies
  (finding/law/means) are English this build, flagged for the native-review pass. Urdu strings are AI-drafted
  and marked `reviewedByNativeSpeaker: false`.
- **Evidence locker / matter model.** v1's DemoContext matter store, 8 failure scenarios, caseWorkflow's
  filing packet — v2's single-thread journey doesn't yet model matters or evidence (Phase 4).
- **Verify gate breadth.** v1's gate checked scripted invariants (scenarios, turn ids, language packs, channel
  metaphors). v2's gate checks integrity + design law + WCAG but has fewer scripted fixtures to assert on — it
  will grow with each phase.

## 4. Test evidence (this build, 2026-10-25)

- Gates: `verify` **PASS** (integrity, design law, presence, 34 WCAG AA pairs × light+dark), `typecheck`
  clean, `build` ✓ (2.95–3.09 s).
- Browser runtime (agent-browser + Chrome 156, 420×900): empty state, golden path end-to-end, demand-notice
  consent gating, all three hard stops, DLSA form with [VERIFY] placeholders, treatment toggle, tell-me-more
  re-route, caution branch, error+retry, offline banner, Urdu RTL (`dir="rtl"` verified at runtime), dark
  mode — **zero console errors across the session**.
- Vision QA on key screens: home ("professional, ChatGPT-like calm, no flaws found"), finding card ("strong
  hierarchy, trust chrome visible"), stop screen ("calm and protective, not punitive").
- Bugs found and fixed during testing: StrictMode double-invoke swallowing scenario seeds; stale conversation
  state when re-seeding from the launcher; duplicated "So far I understand" prefix; duplicated caution intro.

## 5. Verdict

v2 is the right foundation to continue on: it keeps v1's legal-channel spine (1915, e-Daakhil, registered post
AD, DLSA), its anti-fabrication laws, and its consequence-scaled motion philosophy — while replacing the
exhibit-style shell with an app people already know how to use, and the bespoke visual system with a token
architecture that can scale to more scripts, themes and surfaces without re-deriving them per screen. v1
remains the reference for content depth; port from it phase by phase.

# LokAI v2 — Design & Interaction Quality Audit

**Date:** 2026-10-26 · **Auditor lens:** senior product designer, AI–human interaction (portfolio-review pass)
**Method:** live adversarial walkthroughs in Chrome 420×900 (evidence screenshots 40–41), code review of
classifier/copy/tokens, per-language surface inspection. Product laws from `PRODUCT.md` / the 2.0 build prompt
are the measuring stick.

---

## Verdict

**The chassis is genuinely good; the journey intelligence underneath it is not ready for the users this
product is for.** The trust chrome, the calm botanical skin, RTL Urdu, WCAG-verified tokens, and the protective
stop architecture are ahead of most real AI-legal products. But in live testing, the classifier routes a
frightened notice-recipient into a consumer-purchase script, the assistant invents facts while "restating,"
and the most sensitive sentences on the most sensitive screen render in English on a Hindi UI. For a product
whose entire bet is *"the assistant is honest about its limits,"* these are P0/P1, not polish items.

---

## What's working well (keep and protect)

1. **Trust chrome is real and visible** — verification badges default to "not yet verified," three-level
   plain-language confidence, "What I checked" pill always tagged *Simulated in prototype*, [VERIFY] docket
   stamps. No competitor has this.

## Findings — severity ranked

### P0 — journey correctness (the product's core promise)

**P0-1. High-stakes matters route into the consumer script.** Evidence: sending *"I got a legal notice about a
property dispute and I am scared"* produced "That sounds frustrating, and it is a common situation…" followed by
**"When did you buy it?"** (screenshot of run in audit log). A property/court dispute is exactly the matter
class this product must slow down on; instead it got consumer-branch treatment with a purchase-age question.
Root cause: `classifyMatter` has no property/court/legal-notice patterns, and the proceed-branch asks the
mixer-journey's hardcoded question regardless of what the user said. The empathy line ("common situation") also
minimizes distress.

**P0-2. The "restatement" fabricates facts.** Evidence: sending Hinglish *"Mujhe HomeKart se grinder aaya tha,
tuta hua tha, refund nahi mila"* (no price, no replacement-refusal mentioned) returned "So far I understand:
mixer grinder from HomeKart, **₹8,999**, arrived cracked, **refund and replacement both refused**." The
assistant asserted details the user never gave — a direct violation of the product's own A2.3 restatement law,
and the single fastest way to destroy trust with a scared first-time user. Root cause: a `/HomeKart|mixer/i`
shortcut selects the scripted demo restatement for any input that mentions the words.

**P0-3. The stop screen's *why* sentence is English on localized screens.** Evidence: Hindi stop screen shows
headline "मैं यहीं रुक रहा हूँ" but the reason paragraph renders in English ("Housing disputes move fast and
mistakes can cost you your home…"). This is the most emotionally loaded sentence in the product, on the screen
a frightened Hindi speaker sees. `SCOPE_RULES[].why` are English-only and take precedence over the localized
`stopWhy` pack.

### P1 — language readiness across Indian states (the stated goal)

**P1-1. Reply language follows the UI, not the user.** Evidence: Hinglish input got an English reply; switching
UI to Hindi mid-thread leaves the whole prior conversation in English (screenshot 40) while new chrome flips.
Real Indian usage is code-mixed and input-led; the assistant should follow the language (and script) of what
the user wrote for its own replies, independent of chrome language. Minimum viable: script/keyword detection on
input choosing the reply language among the 5 prepared packs.

**P1-2. 5 of 22 scheduled languages, with no honest signpost.** Bengali, Telugu, Marathi ✓, Tamil ✓, Kannada,
Malayalam, Gujarati, Punjabi, Odia, Assamese speakers have no entry point — and the selector doesn't even say
they're coming. v1 had a 12-language registry with visible-but-disabled "not yet prepared" entries (an honesty
pattern this product invented); v2 dropped it. Regression against the "language ready across states" goal.

**P1-3. The serif display voice is Latin-only.** The greeting, "Here's what I heard", "I am going to stop here"
— the emotional register — silently falls back to a **sans** face for hi/mr/ta/ur (`--stk-serif` → Noto Sans
Devanagari/Tamil). No Devanagari/Tamil serif is even installed. India's scripts get the informational voice
everywhere; only English users get the human one. (Urdu is the exception — Nastaliq is inherently
calligraphic.) Fix: `@fontsource/noto-serif-devanagari` + `noto-serif-tamil`, wire `:lang()` serif stacks,
tune sizes on `#/specimen`.

**P1-4. The edit-your-answer affordance is unreachable.** The "Update" button under an answered chip only
renders when the answer is `stale`, which is never set on answers — dead code path (verified live: no Update
button after answering). A2.7 (user control) is broken at exactly the point a user says "actually it was two
years ago."

### P2 — interaction quality (AI-product patterns)

- **P2-1. First acknowledgment lands in ~4.75s** (5 beats × 950ms) with nothing but a stage label. An anxious
  user staring at "Checking the rules…" for 5 seconds feels abandonment, not care. ChatGPT's first token shows
  in ~1s. Fix: acknowledgment beat ≤600ms; slower beats only for the substantive card.
- **P2-2. Composer locks during streaming** (modal-lock anti-pattern; the reference teardown calls this out

- **P2-3. Fake History entries are presented as real** ("Today, 10:24") on a product whose tagline is honesty;

- **P2-6. Tap targets:** theme toggle + language select are 36px (HIG/WCAG-best-practice is 44; current is AA
  minimum, not comfortable for the older skew of this audience).
- **P2-7. Badge text at 11px** (`text-2xs`) carries critical trust semantics ("not yet verified") — below
  comfortable reading size for this audience; 12px minimum recommended.
- **P2-8. Orb halo is faint in dark mode** (recorded previously) — the signature weakens in the theme many
  users will prefer at night.

/* ---------- 4. WCAG AA contrast ---------- */
function parseBlocks(css) {
  const grab = (selector) => {
    const idx = css.indexOf(selector)
    if (idx === -1) return {}
    const start = css.indexOf('{', idx)
    let depth = 1
    let end = start + 1
    while (depth > 0 && end < css.length) {
      if (css[end] === '{') depth++
      if (css[end] === '}') depth--
      end++
    }
    const body = css.slice(start + 1, end - 1)
    const vars = {}
    for (const m of body.matchAll(/--([\w-]+)\s*:\s*([^;]+);/g)) vars[m[1]] = m[2].trim()
    return vars
  }
  return { light: grab(':root'), dark: grab('[data-theme="dark"]') }
}

/** oklch(..) string -> LINEAR sRGB triplet (0..1, no gamma encode) */
function oklchToLinear(str) {
  const m = str.match(/oklch\(\s*([\d.]+)%?\s+([\d.]+)\s+([\d.]+)\s*\)/)
  if (!m) return null
  const L = parseFloat(m[1]) / (str.includes('%') ? 100 : 1)
  const C = parseFloat(m[2])
  const H = (parseFloat(m[3]) * Math.PI) / 180
  const a_ = C * Math.cos(H)
  const b_ = C * Math.sin(H)
  const l_ = L + 0.3963377774 * a_ + 0.2158037573 * b_
  const m_ = L - 0.1055613458 * a_ - 0.0638541728 * b_
  const s_ = L - 0.0894841775 * a_ - 1.291485548 * b_
  const l3 = l_ ** 3
  const m3 = m_ ** 3
  const s3 = s_ ** 3
  return [
    4.0767416621 * l3 - 3.3077115913 * m3 + 0.2309699292 * s3,
    -1.2684380046 * l3 + 2.6097574011 * m3 - 0.3413193965 * s3,
    -0.0041960863 * l3 - 0.7034186147 * m3 + 1.707614701 * s3,
  ]
}

/** relative luminance from a CSS color string (oklch or rgb()) */
function luminance(str) {
  let lin
  if (str.startsWith('rgb(')) {
    const parts = str.match(/[\d.]+/g).map(Number)
    const [r, g, b] = parts.slice(0, 3)
    const dec = (v) => {
      const c = v / 255
      return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4)
    }
    lin = [dec(r), dec(g), dec(b)]
  } else {
    lin = oklchToLinear(str)
  }
  if (!lin) return null
  const clamped = lin.map((c) => Math.min(Math.max(c, 0), 1))
  return 0.2126 * clamped[0] + 0.7152 * clamped[1] + 0.0722 * clamped[2]
}

function contrast(fg, bg) {
  const l1 = luminance(fg)
  const l2 = luminance(bg)
  if (l1 === null || l2 === null) return null
  const [a, b] = l1 >= l2 ? [l1, l2] : [l2, l1]
  return (a + 0.05) / (b + 0.05)
}

const PAIRS = [
  ['fg-primary', 'shell', 4.5],
  ['fg-secondary', 'shell', 4.5],
  ['fg-tertiary', 'shell', 4.5],
  ['fg-primary', 'card', 4.5],
  ['fg-secondary', 'sunken', 4.5],
  ['on-brand-solid', 'brand-solid', 4.5],
  ['brand-fg', 'shell', 4.5],
  ['on-brand-subtle', 'brand-subtle', 4.5],
  ['on-positive-solid', 'positive-solid', 4.5],
  ['on-positive-subtle', 'positive-subtle', 4.5],
  ['on-warning-solid', 'warning-solid', 4.5],
  ['on-warning-subtle', 'warning-subtle', 4.5],
  ['on-danger-solid', 'danger-solid', 4.5],
  ['on-danger-subtle', 'danger-subtle', 4.5],
  ['fg-on-inverted', 'standout', 4.5],
  ['fg-standout-secondary', 'standout', 4.5],
  ['brand-solid', 'shell', 3.0],
  ['positive-solid', 'shell', 3.0],
  ['danger-solid', 'shell', 3.0],
]

{
  const css = readFileSync(join(ROOT, 'src/styles/tokens.css'), 'utf8')
  const { light, dark } = parseBlocks(css)
  for (const [themeName, theme] of [
    ['light', light],
    ['dark', dark],
  ]) {
    const merged = { ...light, ...theme } // dark re-points over light base
    for (const [fgKey, bgKey, min] of PAIRS) {
      const fgVal = merged[`c-${fgKey}`]
      const bg = merged[`c-${bgKey}`]
      if (!fgVal || !bg) {
        fail(`tokens.css: missing var for pair ${fgKey}/${bgKey} (${themeName})`)
        continue
      }
      const ratio = contrast(fgVal, bg)
      if (ratio === null) {
        notes.push(`  ..  ${themeName} ${fgKey}/${bgKey}: skipped (non-lit value)`)
        continue
      }
      if (ratio < min) {
        fail(`WCAG ${themeName}: ${fgKey} on ${bgKey} = ${ratio.toFixed(2)} < ${min}`)
      } else {
        ok(`WCAG ${themeName}: ${fgKey}/${bgKey} = ${ratio.toFixed(2)}`)
      }
    }
  }
}

/** Step 1: editable, copyable WhatsApp draft. */

/**
 * Demand notice behind an explicit review + consent step (A2.7): paper
 * stationery register, every field editable, consent checkbox gates the
 * final render. Nothing is exported or sent by the app itself.
 */
export function DemandNoticeReview({ onBack }: { onBack: () => void }) {
  const { tr } = useApp()
  const [values, setValues] = useState<Record<string, string>>(
    Object.fromEntries(NOTICE_FIELDS.map((f) => [f.key, f.value])),
  )
  const [consented, setConsented] = useState(false)
  const [finalText, setFinalText] = useState<string | null>(null)

  const compose = () =>
    NOTICE_FIELDS.map((f) => {
      if (f.key === 'body') return values.body
      return `${f.label}: ${values[f.key]}`
    })
      .join('\n\n')
      .trim()

  if (finalText !== null) {
    return (
      <div className="scroll-calm flex-1 overflow-y-auto px-3.5 py-4">
        <div className="mx-auto flex max-w-[340px] flex-col gap-3">
          <div className="flex items-center justify-between">

              {tr('back')}
            </Button>
          </div>
          <div className="paper rounded-2xl p-5 font-serif text-sm leading-[28px]" lang="en">
            <pre className="whitespace-pre-wrap font-serif">{finalText}</pre>
          </div>
          <div className="flex flex-wrap gap-2">
            <Button
              variant="primary"
              size="sm"
              leadingIcon={<IconCopy className="size-3.5" />}
              onClick={async () => {
                const ok = await copyText(finalText)
                if (ok) toast.success(tr('copied'))
              }}
            >
              {tr('noticeCopyAll')}
            </Button>
            <Banner tone="info" className="flex-1">
              Copy it, paste it into a document, print on plain paper, and send by registered post with ACKNOWLEDGEMENT
              DUE — keep the receipt.
            </Banner>
          </div>
        </div>
      </div>
    )
  }

  return (
    <div className="scroll-calm flex-1 overflow-y-auto px-3.5 py-4">
      <div className="mx-auto flex max-w-[340px] flex-col gap-3.5">
        <div className="flex items-center justify-between">
          <h2 className="text-sm font-semibold text-fg-primary">{tr('noticeReviewTitle')}</h2>
          <Button variant="ghost" size="sm" leadingIcon={<IconArrowLeft className="size-3.5" />} onClick={onBack}>

import { useState } from 'react'
import { toast } from 'sonner'
import { useApp } from '../../lib/app-context'
import { cn } from '../../lib/cn'
import { legalById } from '../../data/legal-content'
import { Badge } from '../ui/Badge'
import { Card } from '../ui/Card'
import { Textarea } from '../ui/Field'
import { ConfidenceIndicator, type ConfidenceLevel } from '../trust/ConfidenceIndicator'
import { VerificationBadge } from '../trust/VerificationBadge'
import { ReasoningPill } from '../trust/ReasoningPill'
import { CardActions } from './CardActions'

export interface FindingCardData {
  title: string
  whatHappened: string
  lawSays: string
  means: string
  legalId: string
  confidence: ConfidenceLevel
  reasoningSteps: string[]
  /** alternate wording produced by Regenerate */
  variants?: { whatHappened: string; means: string }[]
}

export interface FindingCardProps {
  data: FindingCardData
  stale?: boolean
  onUpdate?: (data: FindingCardData) => void
  onDiscard?: () => void
}

/**
 * The generative finding card: serif heading (the "law register" is a READING
 * surface, allowed), three zones, verified-or-not citation, confidence in
 * plain words, reasoning pill, and full user control.
 */
export function FindingCard({ data, stale, onUpdate, onDiscard }: FindingCardProps) {
  const { tr, lang } = useApp()
  const legal = legalById(data.legalId)
  const [editing, setEditing] = useState(false)
  const [draft, setDraft] = useState(data)
  const [variantIdx, setVariantIdx] = useState(0)
  /** A4b: uppercase + tracking are Latin-only niceties */
  const labelClass = cn(
    'text-2xs font-semibold text-fg-tertiary',
    lang === 'en' && 'uppercase tracking-wide',
  )

  const variants = data.variants ?? []
  const regenerate = () => {
    if (variants.length === 0) {
      toast('No alternate draft prepared for this card')
      return
    }
    const next = (variantIdx + 1) % (variants.length + 1)
    setVariantIdx(next)
    const v = next === 0 ? data : variants[next - 1]!
    const merged = { ...draft, ...v }
    setDraft(merged)
    onUpdate?.(merged)
  }

  const save = () => {
    setEditing(false)
    onUpdate?.(draft)
    toast.success(tr('saveChanges'))
  }

  return (
    <Card className={cn('flex flex-col gap-3.5', stale && 'opacity-70')}>
      {stale && (
        <div className="-mb-1 flex items-center justify-between">
          <Badge tone="warning" variant="subtle">{tr('stale')}</Badge>
        </div>
      )}
      {editing ? (
        <div className="flex flex-col gap-2">
          <Textarea value={draft.title} onChange={(e) => setDraft({ ...draft, title: e.target.value })} rows={2} aria-label="title" />
          <Textarea value={draft.whatHappened} onChange={(e) => setDraft({ ...draft, whatHappened: e.target.value })} aria-label="what happened" />
          <Textarea value={draft.means} onChange={(e) => setDraft({ ...draft, means: e.target.value })} aria-label="what this means" />
        </div>
      ) : (
        <>
          <h3 className="font-serif text-lg font-semibold leading-snug text-fg-primary">
            {draft.title}
          </h3>
          <dl className="flex flex-col gap-3" lang="en">
            <div>
              <dt className={labelClass} lang={lang === 'en' ? undefined : lang}>
                {tr('findingWhatHappened')}
              </dt>
              <dd className="mt-1 text-sm text-fg-primary">{draft.whatHappened}</dd>
            </div>
            <div>
              <dt className={labelClass} lang={lang === 'en' ? undefined : lang}>
                {tr('findingLawSays')}
              </dt>
              <dd className="mt-1 text-sm text-fg-primary">{draft.lawSays}</dd>
              {legal && (
                <div className="mt-1.5 flex flex-wrap items-center gap-2">
                  <span className="font-mono text-2xs text-fg-secondary">
                    {legal.source} · {legal.sectionRef}
                  </span>
                  <VerificationBadge verified={legal.verified} />
                </div>
              )}
            </div>
            <div>
              <dt className={labelClass} lang={lang === 'en' ? undefined : lang}>
                {tr('findingMeans')}
              </dt>
              <dd className="mt-1 text-sm text-fg-primary">{draft.means}</dd>
            </div>
          </dl>
        </>
      )}

      <ConfidenceIndicator level={draft.confidence} />
      <ReasoningPill steps={draft.reasoningSteps} />

      <CardActions
        editing={editing}
        onEdit={() => (editing ? save() : setEditing(true))}
        onRegenerate={regenerate}
        onDiscard={onDiscard}
      />
    </Card>
  )
}

export interface ComposerProps {
  onSend: (text: string, attachments: string[]) => void
  disabled?: boolean
  offline?: boolean
  attachments: string[]
  onAttach: (name: string) => void
  onRemoveAttachment: (name: string) => void
}

const MOCK_DOCS = ['bill-homekart.pdf', 'photo-when-opened.jpg']

/**
 * Large rounded composer (ChatGPT/Gemini register) with a MOCK attachment
 * tray — real file inputs are forbidden by the verify gate.
 */
export function Composer({ onSend, disabled, offline, attachments, onAttach, onRemoveAttachment }: ComposerProps) {
  const { tr } = useApp()
  const [text, setText] = useState('')
  const [trayOpen, setTrayOpen] = useState(false)
  const areaRef = useRef<HTMLTextAreaElement>(null)

  useEffect(() => {
    const el = areaRef.current
    if (!el) return
    el.style.height = 'auto'
    el.style.height = `${Math.min(el.scrollHeight, 140)}px`
  }, [text])

  const submit = () => {
    const value = text.trim()
    if (!value || disabled || offline) return
    onSend(value, attachments)
    setText('')
  }

  return (
    <div className="relative">
      <AnimatePresence>
        {trayOpen && (
          <motion.div
            initial={{ opacity: 0, y: 6, scale: 0.98 }}
            animate={{ opacity: 1, y: 0, scale: 1 }}
            exit={{ opacity: 0, y: 6, scale: 0.98 }}
            transition={{ duration: 0.16 }}
            className="absolute inset-x-0 bottom-full mb-2 rounded-2xl border border-line-default bg-modal p-3 shadow-large"
            role="dialog"
            aria-label={tr('attachTitle')}
          >
            <p className="text-2xs font-semibold text-fg-primary">{tr('attachTitle')}</p>
            <p className="mt-0.5 text-2xs text-fg-tertiary">{tr('attachHint')}</p>
            <div className="mt-2 flex flex-col gap-1">
              {MOCK_DOCS.map((doc) => (
                <button
                  key={doc}
                  type="button"
                  onClick={() => {
                    onAttach(doc)
                    setTrayOpen(false)
                  }}
                  className="flex min-h-11 items-center gap-2.5 rounded-lg px-2 text-start hover:bg-hover-veil"
                >
                  <IconDoc className="size-4 shrink-0 text-fg-tertiary" />
                  <span className="text-sm text-fg-primary">{doc}</span>
                  <span className="text-2xs text-fg-tertiary">(mock)</span>
                </button>
              ))}
            </div>
          </motion.div>
        )}
      </AnimatePresence>

      <div
        className={cn(
          'rounded-3xl border bg-container p-2 transition-colors',
          offline ? 'border-line-default opacity-60' : 'border-line-default focus-within:border-brand-line',
        )}
      >
        {attachments.length > 0 && (
          <div className="flex flex-wrap gap-1.5 px-1 pt-1">
            {attachments.map((a) => (
              <span
                key={a}
                className="inline-flex min-h-9 items-center gap-1.5 rounded-lg bg-sunken px-2.5 text-2xs text-fg-secondary"
              >

                  className="rounded-full p-0.5 text-fg-tertiary hover:text-fg-primary"
                >
                  <IconX className="size-3.5" />
                </button>
              </span>
            ))}
          </div>
        )}

        <div className="flex items-end gap-1.5">
          <button
            type="button"
            aria-label={tr('composerAttach')}

import { useEffect, useRef, type ReactNode } from 'react'
import { cn } from '../../lib/cn'

export interface ThreadProps {
  children: ReactNode
  /** value that changes whenever content grows — drives auto-scroll */
  scrollKey: string | number
  className?: string
}

export function Thread({ children, scrollKey, className }: ThreadProps) {
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const el = ref.current
    if (!el) return
    el.scrollTo({ top: el.scrollHeight, behavior: 'smooth' })
  }, [scrollKey])

  return (
    <div ref={ref} className={cn('scroll-calm flex-1 overflow-y-auto overscroll-contain px-3.5 py-4', className)}>
      <div className="flex flex-col gap-5">{children}</div>
    </div>
  )
}

import { useId, useState, type ReactNode } from 'react'
import { AnimatePresence, motion } from 'motion/react'
import { cn } from '../../lib/cn'
import { IconChevronDown } from './icons'

export interface DisclosureProps {
  title: ReactNode
  subtitle?: ReactNode
  leading?: ReactNode
  defaultOpen?: boolean
  open?: boolean
  onOpenChange?: (open: boolean) => void
  children: ReactNode
  className?: string
}

/** Accessible expand/collapse (button + region), height-animated. */
export function Disclosure({
  title,
  subtitle,
  leading,
  defaultOpen = false,
  open: controlled,
  onOpenChange,
  children,
  className,
}: DisclosureProps) {
  const id = useId()
  const [uncontrolled, setUncontrolled] = useState(defaultOpen)
  const open = controlled ?? uncontrolled
  const toggle = () => {
    const next = !open
    if (controlled === undefined) setUncontrolled(next)
    onOpenChange?.(next)
  }

  return (
    <div className={cn('rounded-2xl border border-line-default bg-card', className)}>
      <button
        type="button"
        aria-expanded={open}
        aria-controls={id}
        onClick={toggle}
        className="flex w-full items-center gap-3 rounded-2xl p-4 text-start hover:bg-hover-veil transition-colors"
      >
        {leading}
        <span className="min-w-0 flex-1">
          <span className="block text-sm font-semibold text-fg-primary">{title}</span>
          {subtitle && <span className="mt-0.5 block text-2xs text-fg-tertiary">{subtitle}</span>}
        </span>
        <motion.span
          animate={{ rotate: open ? 180 : 0 }}
          transition={{ duration: 0.18 }}
          className="shrink-0 text-fg-tertiary"
        >
          <IconChevronDown className="size-4" />
        </motion.span>
      </button>
      <AnimatePresence initial={false}>
        {open && (
          <motion.div
            id={id}
            role="region"
            initial={{ height: 0, opacity: 0 }}
            animate={{ height: 'auto', opacity: 1 }}
            exit={{ height: 0, opacity: 0 }}
            transition={{ duration: 0.22, ease: [0.22, 1, 0.36, 1] }}
            className="overflow-hidden"
          >
            <div className="border-t border-line-subtle px-4 pb-4 pt-3">{children}</div>
          </motion.div>
        )}
      </AnimatePresence>
    </div>
  )
}

      })}

}

/**

export interface ScopeDecision {
  tier: ScopeTier
  ruleId?: string
  label: string
  why: string
  /** matched = a rule fired; uncertain = downgrade law applied */
  certainty: 'matched' | 'uncertain'
}

/** Hard-stop wins over caution wins over proceed. Uncertain input -> caution. */
export function classifyMatter(text: string): ScopeDecision {
  const hit = SCOPE_RULES.find((r) => r.patterns.some((p) => p.test(text)))
  if (hit) {
    return { tier: hit.tier, ruleId: hit.id, label: hit.label, why: hit.why, certainty: 'matched' }
  }
  const looksConsumer = /(refund|replace|defect|crack|broken|broke|bill|invoice|seller|order|delivered|warranty|product|item|refund|money back|उत्पाद|रिफंड|खराब|विक्रेता|वस्तू|पैसा|परत|रिफंड|பொருள்|பணம்|رفنڈ|خراب|پیسہ)/i
  if (looksConsumer.test(text) || text.trim().length > 25) {
    return {
      tier: 'proceed',
      label: 'Consumer matter',
      why: '',
      certainty: 'matched',
    }
  }
  // DOWNGRADE LAW in action: too little signal to proceed silently.
  return {
    tier: 'caution',
    label: 'Not sure what this is yet',
    why: 'I am not sure I have the full picture. Tell me a little more and I will route you correctly.',
    certainty: 'uncertain',
  }
}

/** The user's explicit re-entry: "this is actually a consumer matter". */
export function reRouteAsCaution(): ScopeDecision {
  return {
    tier: 'caution',
    label: 'Needs care',
    why: 'Thank you. Because you told me this touches another area, I will stay careful: the free steps below are still safe, and a human helper should double-check the boundary.',
    certainty: 'matched',
  }
}

import { createContext, useCallback, useContext, useEffect, useMemo, useState, type ReactNode } from 'react'
import { LANGUAGES, type LangCode } from '../data/languages'
import { UI, type UiKey } from '../data/i18n'

type Theme = 'light' | 'dark'

interface AppContextValue {
  theme: Theme
  toggleTheme: () => void
  lang: LangCode
  setLang: (l: LangCode) => void
  /** localized UI chrome string */
  tr: (key: UiKey) => string
  direction: 'ltr' | 'rtl'
}

const AppContext = createContext<AppContextValue | null>(null)

function readStored<T extends string>(key: string, fallback: T, valid: readonly T[]): T {
  try {
    const v = window.localStorage.getItem(key)
    if (v && (valid as readonly string[]).includes(v)) return v as T
  } catch {
    /* private mode etc. */
  }
  return fallback
}

export function AppProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>(() => readStored('lokai.theme', 'light', ['light', 'dark'] as const))
  const [lang, setLangState] = useState<LangCode>(() => readStored('lokai.lang', 'en', ['en', 'hi', 'mr', 'ta', 'ur'] as const))

  useEffect(() => {
    document.documentElement.dataset.theme = theme
  }, [theme])

  useEffect(() => {
    const cfg = LANGUAGES[lang]
    document.documentElement.lang = lang
    document.documentElement.dataset.script = cfg.script
    document.documentElement.dir = cfg.direction
  }, [lang])

  const toggleTheme = useCallback(() => {
    setTheme((prev) => {
      const next = prev === 'light' ? 'dark' : 'light'
      try {
        window.localStorage.setItem('lokai.theme', next)
      } catch {
        /* ignore */
      }
      return next
    })
  }, [])

  const setLang = useCallback((l: LangCode) => {
    setLangState(l)
    try {
      window.localStorage.setItem('lokai.lang', l)
    } catch {
      /* ignore */
    }
  }, [])

  const value = useMemo<AppContextValue>(
    () => ({
      theme,
      toggleTheme,
      lang,
      setLang,
      tr: (key: UiKey) => UI[key][lang],
      direction: LANGUAGES[lang].direction,
    }),
    [theme, toggleTheme, lang, setLang],
  )

  return <AppContext.Provider value={value}>{children}</AppContext.Provider>
}

  if (!ctx) throw new Error('useApp outside AppProvider')

}

/**
 * Deterministic staged-progress engine (design law ported from v1's
 * responseEngine): responses arrive as narrated beats, durations scale with
 * the consequence class of the turn (heavier consequence = faster, fewer
 * theatrical beats), everything is skippable, and prefers-reduced-motion
 * collapses delays to near-zero. No model, no network — ever.
 */
export type BeatClass = 'stop' | 'caution' | 'explain' | 'disclose' | 'progress'

export const STAGE_MS_BY_CLASS: Record<BeatClass, number> = {
  stop: 260,
  caution: 520,
  explain: 950,
  disclose: 700,
  progress: 620,
}

export interface Beat {
  label: string
}

export const BEATS: Record<BeatClass, Beat[]> = {
  stop: [
    { label: 'stageReading' },
    { label: 'stageChecking' },
  ],
  caution: [
    { label: 'stageReading' },
    { label: 'stageChecking' },
    { label: 'stageWriting' },
  ],
  explain: [
    { label: 'stageReading' },
    { label: 'stageChecking' },
    { label: 'stageChecking' },
    { label: 'stageWriting' },
    { label: 'stageWriting' },
  ],
  disclose: [
    { label: 'stageReading' },
    { label: 'stageChecking' },
    { label: 'stageWriting' },
  ],
  progress: [
    { label: 'stageReading' },
    { label: 'stageWriting' },
  ],
}

const prefersReducedMotion = () =>
  typeof window !== 'undefined' &&
  window.matchMedia('(prefers-reduced-motion: reduce)').matches

export interface RunOptions {
  /** jump straight to completion (skip affordance) */
  skip?: boolean
  /** simulate a transport failure after the first beat (error-state demo) */
  failAfterFirstBeat?: boolean
}

export class SimulatedFailure extends Error {
  constructor() {
    super('simulated transport failure')
  }
}

/**
 * Walks the beat list for a class, invoking onStage with each beat label.
 * Resolves when done — or rejects with SimulatedFailure when the failure
 * injection is on. The caller decides what "the turn" is; this only paces it.
 */
export function runBeats(
  beatClass: BeatClass,
  onStage: (label: string, index: number) => void,
  opts: RunOptions = {},
): Promise<void> {
  const beats = BEATS[beatClass]
  const base = STAGE_MS_BY_CLASS[beatClass]
  const ms = opts.skip || prefersReducedMotion() ? 1 : base

  return new Promise<void>((resolve, reject) => {
    let i = 0
    const step = () => {
      if (i >= beats.length) {
        resolve()
        return
      }
      onStage(beats[i]!.label, i)
      if (opts.failAfterFirstBeat && i === 0) {
        window.setTimeout(() => reject(new SimulatedFailure()), ms * 2)
        return
      }
      i += 1
      window.setTimeout(step, ms)
    }
    step()
  })
}

/**
 * Intl formatting (A4b rules 6-9). Single source for numbers, dates and
 * grapheme-safe truncation. Latin digits everywhere (languages.ts decision).
 */
const inr = new Intl.NumberFormat('en-IN', {
  style: 'currency',
  currency: 'INR',
  maximumFractionDigits: 0,
})

const dateFmt = new Intl.DateTimeFormat('en-IN', {
  day: 'numeric',
  month: 'short',
  year: 'numeric',
})

export function formatINR(amount: number): string {
  return inr.format(amount)
}

export function formatDate(iso: string): string {
  return dateFmt.format(new Date(iso))
}

const segmenter =
  typeof Intl !== 'undefined' && 'Segmenter' in Intl
    ? new Intl.Segmenter('en', { granularity: 'grapheme' })
    : null

/** Truncation that respects grapheme clusters (conjuncts, matras). */
export function truncateGraphemes(text: string, max: number): string {
  if (!segmenter) return text.length <= max ? text : text.slice(0, max - 1) + '…'
  const segments = Array.from(segmenter.segment(text), (s) => s.segment)
  if (segments.length <= max) return text
  return segments.slice(0, max - 1).join('') + '…'
}

export async function copyText(text: string): Promise<boolean> {
  try {
    await navigator.clipboard.writeText(text)
    return true
  } catch {
    return false
  }
}

import { useEffect, useState } from 'react'

export interface HashRoute {
  path: string
  params: URLSearchParams
}

function parse(): HashRoute {
  const raw = window.location.hash.replace(/^#/, '') || '/'
  const [path, query = ''] = raw.split('?')
  return { path: path === '' ? '/' : path, params: new URLSearchParams(query) }
}

export function navigate(to: string) {
  window.location.hash = to.startsWith('/') ? to.slice(1) : to
}

export function useHashRoute(): HashRoute {
  const [route, setRoute] = useState<HashRoute>(parse)
  useEffect(() => {
    const onHash = () => setRoute(parse())
    window.addEventListener('hashchange', onHash)
    return () => window.removeEventListener('hashchange', onHash)
  }, [])
  return route
}

  type NoticeField,

import { IconDoc, IconExternal } from '../components/ui/icons'
import { runBeats } from '../lib/engine'

type Phase = 'reading' | 'interpreting' | 'done'

/**
 * Phase 3 — notice interpreter. Explains ONLY what the notice says; every
 * extracted field is editable-in-place and taps through to the exact
 * original clause (tap-to-source). Disputes route to human help.
 */
export default function NoticePage() {
  const { tr, lang } = useApp()
  const [phase, setPhase] = useState<Phase>('reading')
  const [openField, setOpenField] = useState<NoticeField | null>(null)
  const [values, setValues] = useState<Record<string, string>>(
    Object.fromEntries(NOTICE_FIELDS.map((f) => [f.id, f.value])),
  )
  const [activeClause, setActiveClause] = useState<number | null>(null)
  const clauseRefs = useRef<(HTMLLIElement | null)[]>([])

  // deterministic reading beats, then the interpretation (StrictMode-safe:
  // re-running only re-walks the beats and re-sets phase)
  useEffect(() => {
    let cancelled = false
    runBeats('disclose', (label) => {
      if (label === 'stageWriting' && !cancelled) setPhase('interpreting')
    }).then(() => {
      if (!cancelled) setPhase('done')
    })
    return () => {
      cancelled = true
    }
  }, [])

  const tapField = (field: NoticeField) => {
    setOpenField(openField?.id === field.id ? null : field)
    setActiveClause(field.clauseIndex)
    clauseRefs.current[field.clauseIndex]?.scrollIntoView({ behavior: 'smooth', block: 'center' })
  }

  const legal = legalById('mmc-property-tax')

  if (phase !== 'done') {
    return (
      <AppShell showTabs={false} topBarExtra={<Button variant="ghost" size="sm" onClick={() => history.back()}>{tr('back')}</Button>}>
        <div className="flex flex-1 flex-col items-center justify-center gap-5 px-8">
          <IconDoc className="size-10 text-fg-tertiary" />
          <p className="text-center text-sm text-fg-secondary">
            {phase === 'reading' ? tr('stageReading') : tr('stageChecking')}…{' '}
            <span className="font-mono text-2xs" lang="en">{NOTICE_DOC.fileName}</span>
          </p>
          <div className="flex w-full max-w-[280px] flex-col gap-2">
            <Skeleton className="h-3.5 w-4/5" />
            <Skeleton className="h-3.5 w-3/5" />
            <Skeleton className="h-3.5 w-2/3" />
          </div>
          <Badge tone="warning" variant="subtle">{tr('simulatedTag')}</Badge>
        </div>
      </AppShell>
    )
  }

  return (
    <AppShell showTabs={false} topBarExtra={<Button variant="ghost" size="sm" onClick={() => history.back()}>{tr('back')}</Button>}>
      <div className="scroll-calm flex-1 overflow-y-auto px-4 py-5">
        <div className="mx-auto flex max-w-[340px] flex-col gap-4">
          {/* what this means */}
          <section className="rounded-2xl border border-line-default bg-card p-4">
            <h1 className="font-serif text-xl font-semibold leading-snug text-fg-primary">{tr('noticeMeaning')}</h1>
            <p className="mt-2 text-sm leading-relaxed text-fg-primary">{NOTICE_SUMMARY[lang]}</p>
            <p className="mt-2 text-2xs text-fg-tertiary" lang="en">
              {NOTICE_DOC.authority} · {NOTICE_DOC.sourceLangLabel}
            </p>
          </section>

          {/* key points — editable, tap-to-source */}
          <section className="flex flex-col gap-2">
            <h2 className="text-sm font-semibold text-fg-primary">{tr('keyPoints')}</h2>
            <ol className="flex flex-col gap-2">
              {NOTICE_FIELDS.map((field, i) => (
                <li key={field.id}>
                  <div className="rounded-2xl border border-line-default bg-card">
                    <button
                      type="button"
                      aria-expanded={openField?.id === field.id}
                      onClick={() => tapField(field)}
                      className="flex w-full items-center gap-3 p-3.5 text-start"
                    >
                      <span
                        className="flex size-6 shrink-0 items-center justify-center rounded-full bg-brand-subtle font-mono text-2xs font-semibold text-on-brand-subtle"
                        aria-hidden="true"
                      >
                        {i + 1}
                      </span>
                      <span className="min-w-0 flex-1">
                        <span className="block text-2xs text-fg-tertiary">{field.label}</span>
                        <span className="block text-sm font-medium text-fg-primary">{values[field.id]}</span>
                      </span>
                      {field.confidence !== 'clear' && (
                        <Badge tone="warning" variant="subtle">{tr('confLikely')}</Badge>
                      )}
                    </button>
                    {openField?.id === field.id && (
                      <div className="border-t border-line-subtle p-3.5">
                        <input
                          value={values[field.id] ?? ''}
                          onChange={(e) => setValues((v) => ({ ...v, [field.id]: e.target.value }))}
                          aria-label={field.label}
                          className="min-h-11 w-full rounded-lg border border-line-default bg-container px-3 text-sm text-fg-primary focus-visible:border-brand-line focus-visible:outline-none"
                        />
                        <p className="mt-1.5 text-2xs text-fg-tertiary">{tr('confLikelyDesc')}</p>
                        <ConfidenceIndicator level={field.confidence} className="mt-2" />
                      </div>
                    )}
                  </div>
                </li>
              ))}
            </ol>
          </section>

          {/* what you can do next */}
          <section className="flex flex-col gap-2">

              <span className="text-2xs text-fg-tertiary">{tr('viewAll')}</span>
            </div>
            {legal && (
              <div className="flex items-center gap-2.5 rounded-xl border border-line-default bg-card px-3.5 py-3" lang="en">

            <ol className="flex flex-col gap-1.5" lang="mr">

import { useEffect, useRef, useState } from 'react'
import { motion } from 'motion/react'
import { toast } from 'sonner'
import { useApp } from '../lib/app-context'
import { navigate } from '../lib/router'
import { LANG_ORDER, LANGUAGES, type LangCode } from '../data/languages'
import { VOICE_SAMPLES, formatClock } from '../data/voice-samples'
import { AppShell } from '../components/ui/shell'
import { Badge } from '../components/ui/Badge'
import { Button } from '../components/ui/Button'
import { VoiceOrb } from '../components/voice/VoiceOrb'
import { IconCamera, IconKeyboard, IconMic, IconPencil, IconStop } from '../components/ui/icons'

type CaptureState = 'listening' | 'review'

/**
 * Simulated voice capture (Phase V): listening (timer + waveform, mic never
 * touched) -> review & send ("Here's what I heard", editable transcript).
 * The whole surface is tagged simulated (A7).
 */
export default function VoiceCapturePage() {
  const { tr, lang } = useApp()
  const [phase, setPhase] = useState<CaptureState>('listening')
  const [seconds, setSeconds] = useState(0)
  const [transcript, setTranscript] = useState(VOICE_SAMPLES[lang])
  const [detected, setDetected] = useState<LangCode | 'auto'>(lang)
  const secondsRef = useRef(0)

  useEffect(() => {
    if (phase !== 'listening') return
    const t = window.setInterval(() => {
      secondsRef.current += 1
      setSeconds(secondsRef.current)
    }, 1000)
    return () => window.clearInterval(t)
  }, [phase])

  const stop = () => setPhase('review')

  const send = () => {
    const text = transcript.trim()
    if (!text) {
      toast.error(tr('errorTitle'))
      return
    }
    try {
      window.sessionStorage.setItem('lokai.pendingTranscript', text)
    } catch {
      /* ignore */
    }
    navigate('/')
  }

  if (phase === 'listening') {
    return (
      <AppShell showTabs={false} topBarExtra={<Button variant="ghost" size="sm" onClick={() => navigate('/')}>{tr('back')}</Button>}>
        <div className="flex flex-1 flex-col items-center justify-between px-6 pb-8 pt-10">
          <div className="flex flex-col items-center gap-1">
            <h1 className="font-serif text-2xl font-semibold text-fg-primary">{tr('listening')}</h1>
            <p className="font-mono text-sm text-fg-tertiary" lang="en">{formatClock(seconds)}</p>
          </div>

          <div className="flex flex-col items-center gap-7">
            <button type="button" onClick={stop} aria-label={tr('tapToStop')} className="rounded-full outline-offset-8">
              <VoiceOrb state="listening" size="lg" />
            </button>
            <div className="w-full max-w-[300px] rounded-2xl border border-line-default bg-card p-4">
              <div className="waveform" aria-hidden="true">
                {Array.from({ length: 28 }, (_, i) => (
                  <span key={i} className="wave-bar" />
                ))}
              </div>
              <p className="mt-3 text-sm leading-relaxed text-fg-secondary">{VOICE_SAMPLES[lang]}</p>
            </div>
            <p className="max-w-[280px] text-center text-2xs text-fg-tertiary">{tr('speakNaturally')}</p>
          </div>

          <div className="flex w-full max-w-[300px] flex-col items-center gap-2.5">
            <Button variant="secondary" size="lg" block leadingIcon={<IconStop className="size-4 text-danger-fg" />} onClick={stop}>
              {tr('tapToStop')}
            </Button>
            <Badge tone="warning" variant="subtle">{tr('simulatedTag')}</Badge>
            <p className="text-2xs text-fg-tertiary">{tr('simulatedVoiceNote')}</p>
          </div>
        </div>
      </AppShell>
    )
  }

  return (
    <AppShell showTabs={false} topBarExtra={<Button variant="ghost" size="sm" onClick={() => setPhase('listening')}>{tr('back')}</Button>}>
      <div className="scroll-calm flex-1 overflow-y-auto px-4 py-5">
        <div className="mx-auto flex max-w-[340px] flex-col gap-4">
          <div>
            <h1 className="font-serif text-2xl font-semibold leading-snug text-fg-primary">{tr('heardTitle')}</h1>
            <p className="mt-1 text-2xs text-fg-tertiary">{tr('heardSub')}</p>
          </div>

          <div className="relative rounded-2xl border border-line-default bg-card p-4">
            <textarea
              value={transcript}
              onChange={(e) => setTranscript(e.target.value)}
              rows={6}
              aria-label={tr('heardTitle')}
              className="w-full resize-none bg-transparent font-serif text-base leading-relaxed text-fg-primary focus:outline-none"
            />
            <span className="absolute end-3 top-3 text-fg-tertiary" aria-hidden="true">
              <IconPencil className="size-4" />
            </span>
          </div>

          <div className="flex flex-col gap-1.5">
            <p className="text-2xs font-medium text-fg-secondary">{tr('detectedLang')}</p>
            <div className="flex items-center gap-2">
              <select
                value={detected}
                onChange={(e) => setDetected(e.target.value as LangCode | 'auto')}
                aria-label={tr('detectedLang')}
                className="min-h-11 flex-1 rounded-xl border border-line-default bg-container px-3 text-sm text-fg-primary focus-visible:border-brand-line focus-visible:outline-none"
              >
                <option value="auto">{`${LANGUAGES[lang].english} (${tr('autoDetect')})`}</option>
                {LANG_ORDER.map((c) => (
                  <option key={c} value={c}>{LANGUAGES[c].english}</option>
                ))}
              </select>
            </div>
          </div>

          <div className="flex flex-col gap-1.5">
            <p className="text-2xs font-medium text-fg-secondary">{tr('addDetails')}</p>
            {(
              [
                { icon: <IconCamera className="size-4" />, label: tr('addFilePhoto') },
                { icon: <IconMic className="size-4" />, label: tr('addLocation') },
                { icon: <IconKeyboard className="size-4" />, label: tr('specifyDate') },
              ] as const
            ).map((row) => (
              <button
                key={row.label}
                type="button"
                onClick={() => toast('Attachments are mocked in this prototype')}
                className="flex min-h-11 items-center gap-2.5 rounded-xl border border-line-default bg-container px-3 text-start text-sm text-fg-primary transition-colors hover:bg-component-hover"
              >
                <span className="text-fg-tertiary">{row.icon}</span>
                {row.label}
              </button>
            ))}
          </div>

          <motion.div initial={{ opacity: 0, y: 8 }} animate={{ opacity: 1, y: 0 }} transition={{ duration: 0.22 }}>
            <Button variant="primary" size="lg" block onClick={send}>
              {tr('sendToLokai')}
            </Button>
            <p className="mt-2 text-center text-2xs text-fg-tertiary">
              <Badge tone="warning" variant="subtle">{tr('simulatedTag')}</Badge>
            </p>
          </motion.div>
        </div>
      </div>
    </AppShell>
  )
}
